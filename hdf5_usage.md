# Spot-RL HDF5 Dataset Usage Guide

This document describes how to parse, use, and understand the HDF5 data collected from the Spot-RL stack. 

The HDF5 log files are entirely self-contained. **No repository code or special structural imports are required to read them.** An external agent only requires standard Python libraries (`h5py` and `numpy`) to use this data for training, analysis, or evaluation.

Below are the instructions and code snippets for extracting the two main types of HDF5 files generated by the stack.

---

## 1. Episode-Based Datasets (`datasets/*.hdf5`)
These files capture discrete trajectories (e.g., Isaac Sim episodes or recorded demonstrations). The architecture mimics common offline RL dataset formats (like Robomimic), grouping data into hierarchical "demos."

### Data Structure
- `data/`
  - `demo_0/`
    - `actions`: `(N, 19)` -> Joint actions applied (12 base + 7 arm).
    - `processed_actions`: `(N, 19)` -> Post-processed actions (if applicable).
    - `states`: Internal states of the simulation/robot.
    - `obs/` (Dictionary of observations)
      - `base_ang_vel`: `(N, 3)` -> Base angular velocity. 
      - `base_lin_vel`: `(N, 3)` -> Base linear velocity.
      - `projected_gravity`: `(N, 3)` -> Projected gravity vectors.
      - `joint_pos`, `joint_vel`: `(N, 19)` -> Full joint positions and velocities.
      - `default_joint_pos`, `joint_pos_rel`, `joint_vel_rel`: Relative joint telemetry.
      - `root_ang_vel_w`, `root_lin_vel_w`, `root_quat_w`: World frame root states.
      - `joint_ids`: IDs of joints.
      - `sim_time`: Simulation timestamps.
  - `demo_1/`
  - ... (and so on)

### Usage Snippet
```python
import h5py
import numpy as np

filepath = "isaac_spot_dataset_2026-04-16_10-14-24.hdf5"

with h5py.File(filepath, "r") as f:
    # List all demos (episodes) in the file
    demos = list(f["data"].keys())
    print("Demos found:", demos)

    for demo_key in demos:
        demo_grp = f["data"][demo_key]
        
        # Extract actions
        actions = np.array(demo_grp["actions"])
        
        # Extract specific observations
        obs_grp = demo_grp["obs"]
        joint_positions = np.array(obs_grp["joint_pos"])
        projected_gravity = np.array(obs_grp["projected_gravity"])
        
        print(f"[{demo_key}] Actions shape: {actions.shape}")
        print(f"[{demo_key}] Joint position obs shape: {joint_positions.shape}")
```

## 2. Flat Streaming Logs (`spot_isaac_real_*.hdf5`)
These logs are generated during real-time deployment (e.g., via `spot_rl_demo.py`) and record continuous arrays keyed directly at the root of the file.

### Data Structure (Typical Fields)
- `commanded_action`: `(N, 12)` -> Control outputs for the 12 base joints (Spot legs).
- `raw_joint_positions`: `(N, 19)` -> Full state for base (12) and arm (7).
- `raw_joint_velocities`: `(N, 19)` 
- `raw_joint_loads`: `(N, 19)`
- `raw_base_linear_velocity`: `(N, 3)` (X, Y, Z)
- `raw_base_angular_velocity`: `(N, 3)` (X, Y, Z)
- `raw_projected_gravity`: `(N, 3)` (X, Y, Z)
- `spot_current_positions`, `spot_current_velocities`: `(N, 19)`

### Usage Snippet
```python
import h5py
import numpy as np

filepath = "spot_isaac_real_20260428_150123.hdf5"

with h5py.File(filepath, "r") as f:
    # Iterate dynamically through all keys
    for key in f.keys():
        data = np.array(f[key])
        print(f"Dataset '{key}' has shape {data.shape}")

    # Explicit extractions
    actions_base = np.array(f["commanded_action"])      # shape (N, 12)
    positions_all = np.array(f["raw_joint_positions"])  # shape (N, 19)
    lin_vel = np.array(f["raw_base_linear_velocity"])   # shape (N, 3)
```

## Constants & Context (No Repo Dependencies Needed)
To properly interpret the `12` or `19` dimensional arrays, you need to know the joint order. **You do not need to pull the Python codes from the repo**; just copy these standard mappings directly into your external agent/script:

```python
# 12-DOF Spot Base Joints (Legs)
ORDERED_JOINT_NAMES_BASE = [
    "fl_hx", "fl_hy", "fl_kn",  # Front-Left (Hip X, Hip Y, Knee)
    "fr_hx", "fr_hy", "fr_kn",  # Front-Right
    "hl_hx", "hl_hy", "hl_kn",  # Hind-Left
    "hr_hx", "hr_hy", "hr_kn",  # Hind-Right
]

# 7-DOF Spot Arm Joints
ORDERED_JOINT_NAMES_ARM = [
    "arm_sh0", "arm_sh1", 
    "arm_el0", "arm_el1", 
    "arm_wr0", "arm_wr1", 
    "arm_f1x"
]

# 19-DOF Full Robot Joints
ORDERED_JOINT_NAMES_FULL = ORDERED_JOINT_NAMES_BASE + ORDERED_JOINT_NAMES_ARM
```

### Note on 3D/4D Vectors
- `(N, 3)` Vectors generally follow `[X, Y, Z]` logic in the local frame.
- `(N, 4)` Vectors (like Quaternions) generally follow `[X, Y, Z, W]`.
